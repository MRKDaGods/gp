# Runtime requirements for local workflows, the FastAPI backend, and Kaggle
# notebooks. Every version below is exact-pinned to the combination that was
# verified to import and run cleanly together (Python 3.13.9, Windows,
# CUDA 12.4 GPU). Do not loosen these back to ranges without re-verifying -
# several of these packages (boxmot, opencv) have known cross-version
# breakage described inline below.
#
# INSTALL (in this exact order):
#   1) pip install -r requirements.txt
#   2) (GPU only - optional) pip install torch==2.6.0+cu124 torchvision==0.21.0+cu124 --index-url https://download.pytorch.org/whl/cu124
#      Step 1 already installs a working CPU build of torch/torchvision
#      (pulled in transitively by open-clip-torch/timm/torchreid). Step 2
#      overwrites it with the CUDA 12.4 build if you have an NVIDIA GPU.
#   3) pip install --no-deps boxmot==12.0.2
#      MANDATORY, and MUST be its own --no-deps command. boxmot's own
#      metadata hard-pins an old numpy/lapx/regex/torchvision (see note
#      below), so installing it normally either fails outright (old numpy
#      has no wheel for Python 3.13 and fails to build from source) or
#      forces a ResolutionImpossible conflict against the versions pinned
#      here. --no-deps skips boxmot's stale pins entirely; the versions
#      already installed in step 1 are what boxmot actually runs against,
#      and that combination is verified working (src/stage1_tracking/tracker.py).
#   4) pip install --force-reinstall --no-deps opencv-python-headless==5.0.0.93
#      MANDATORY, always run this last. ultralytics (step 1) declares a hard
#      dependency on opencv-python (the GUI build), so step 1 silently pulls
#      it in and it overwrites the headless build's files in the shared
#      `cv2/` site-packages directory - `import cv2` keeps working but is now
#      running the wrong (non-headless) variant. Step 4 forces headless back
#      on top. Never run `pip uninstall opencv-python` by itself afterward:
#      the two packages share files on disk, so uninstalling one deletes
#      files the other needs and breaks `import cv2` entirely until you
#      re-run step 4.
#
# `python start.py` only launches the already-installed backend + frontend;
# it does not install dependencies. Run the 4 steps above first.
