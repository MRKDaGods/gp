# ATHAR web (Phase 5)

Next.js 16 (App Router, Turbopack) + Tailwind 4 + next-intl. Arabic is the
default locale and renders RTL from day 1; English is the engineering
locale. The v1 frontend leftovers live in `/frontend/` (gitignored) and are
not part of this app.

## Dev

```bash
pnpm install
pnpm dev          # http://localhost:3000
```

Run the API next to it (repo root):

```bash
.venv-v2/Scripts/athar serve            # http://localhost:8000
.venv-v2/Scripts/athar users add you --password ... --role investigator
```

Open the app via **localhost** (not 127.0.0.1): auth is a SameSite session
cookie, and `localhost` / `127.0.0.1` are different sites — the default API
base is `http://localhost:8000` (`NEXT_PUBLIC_ATHAR_API` overrides).

## Generated API client

`src/lib/api/` is generated by hey-api from `openapi.json` (a committed
snapshot of the FastAPI schema). After API changes, refresh the snapshot
(repo root, writes `web/openapi.json` from `create_app().openapi()` — see
`web/openapi-ts.config.ts`) and regenerate:

```bash
pnpm generate:api
```

Never edit `src/lib/api/**` by hand; it is excluded from ESLint.
